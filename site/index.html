A short field procedure

Proof the file people will actually see.

Export Proof surveys the approved browser view first, then checks the distributed artifact against that map. It never edits your work.

  1. 01

    Fix the reference

    Open the exact canvas view you approved. The extension records visible text, accessible object names, bounds, and a screenshot of the largest canvas region.

  2. 02

    Pin the export

    Drop in a PNG, JPG, WebP, or PDF. The first PDF page is rendered locally; optional OCR only runs when your browser provides an on-device detector.

  3. 03

    Read the field notes

    Review numbered marks for frame drift, missing edge detail, changed object shapes, and ink that reaches the crop. Save the annotated proof with your release.

Every warning points back to a place.
